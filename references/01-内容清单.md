# 01 · 内容清单（course.js 字段契约）

`course.js` 是一节课的全部内容。它同时给浏览器和 Node 用（文件头是 UMD 包装，别删）：

```js
(function (root, factory) {
  var C = factory();
  if (typeof module === 'object' && module.exports) module.exports = C;  // Node: server.js
  else root.COURSE = C;                                                  // 浏览器: app.js
})(typeof self !== 'undefined' ? self : this, function () { ... });
```

---

## meta

| 字段 | 必填 | 说明 |
|---|---|---|
| `title` | ✅ | 课程全名。服务端 `state.title`、浏览器标签页标题都用它 |
| `kicker` | | 封面副标题（一般只用于第 1 页文案，引擎不读） |
| `brand` | ✅ | 学生端左上角品牌名 + 登录页标题 |
| `brandEmoji` | | 品牌 emoji，缺省 `📘` |
| `origin` | ✅ | 全班出发地。**会进 AI 提示词**，写成「山东省日照市」这种完整形式 |
| `duration` | ✅ | 行程/任务时长，如「1 天 1 夜」。**也进提示词**，用于禁止模型说"第二天" |
| `region` | | 省市前缀，用于从目的地字符串里剥城市名（「山东省淄博市·…」→「淄博」） |
| `grade` | | 学段，用于 AI 人设：「你是一名**小学三年级**信息科技课堂里的助手」 |
| `subject` | | 学科，同上 |
| `mindMapRoot` | | 导图根部文字，如「🌊 黄河1日1夜游 · 行程规划」 |
| `tripLabel` | | 平台核实页与登录页显示的出行日期，如「10月1日」 |
| `tripDates` | | `{ d:'2026-10-01', ci:'2026/10/01', co:'2026/10/02' }`，只给携程备查链接用 |
| `defaultCity` | | 认不出城市时的兜底，如「东营」 |

`kicker` / `grade` / `subject` 这三个写好了，AI 的语气就对一半。

## teams

```js
{ name: '黄河一号', color: '#f4a259', dest: '山东省济南市·百里黄河风景区（黄河下游城市段）', city: '济南' },
{ name: '教师',   color: '#8b93a7', dest: '山东省济南市·百里黄河风景区（黄河下游城市段）', city: '济南', demo: true }
```

| 字段 | 说明 |
|---|---|
| `name` | 组名。**同时是服务端和前端的主键**，改名前先确认没有别的地方引用 |
| `color` | 组色，排行榜色块、认领按钮都用它 |
| `dest` | 本组目的地全名。**直接进 AI 提示词的硬规则**（"你提到的地点必须都在济南」） |
| `city` | 城市短名，拼平台查询链接、判城市用 |
| `demo` | `true` = 教师组：功能全开，但不进排行、不计进度、不参与互评 |

**组的数量决定课堂形态**：6 组 + 教师组适合机房（4 人一组）；少于 4 组就别做岗位分工了，改做 `interactive-lesson-deck`。

**目的地不要全员相同。** 每组去不同城市/景点，互评才有内容可看，汇报才不雷同。

## roles

一个岗位 = 一个 AI 助手 = 行程卡的一行。这是整套设计的骨架。

```js
{
  name: '交通规划师',          // 岗位名。scope.name 会拿它做匹配，别写会和别的岗位混淆的词
  emoji: '🚄',
  cardRow: '交通工具',         // 对应 cardRows[].key，必须存在
  roleWord: '车次',            // 平台按钮文案「打开出行查询 · 查车次」
  platformKind: 'train',      // train | sight | hotel | rest，决定平台页显示哪类数据
  cards: {                    // 学生要填的四张卡（也是 AI 的 system prompt 素材）
    role: '我是交通规划师助手',
    goal: '帮我选出最合适的交通方式',
    know: '火车、大巴、票价、乘车时间',
    rules: '给 2~3 个方案，并说明优缺点',
    bad: '尽量多说，把行程写满就好'      // "诱饵"规矩：故意写坏的，让学生对比哪种提示词更好用
  },
  scope: {                    // AI 硬约束，见 references/03
    name: '交通',
    focus: '怎么从{origin}到{dest}：坐什么车、大概多久、到哪一站下、怎么换乘往返',
    avoid: '景点、住宿、美食',
    kw: ['高铁','动车','火车','车次','换乘',…]
  },
  subProblems: [              // 本岗位的子问题，会和其他岗位混在一起让学生挑
    { id: 'p1', text: '去黄河坐火车还是坐大巴' },
    { id: 'p6', text: '从车站到景区怎么换乘' }
  ]
}
```

要点：

- **`bad` 这张卡是教学道具**，不是笔误。课上要让学生对比「好规矩」和「坏规矩」问出来的答案差多少。
- **`subProblems` 每岗 2 条最合适**：1 条太单薄，3 条以上挑起来变成体力活。
- **`kw` 要写"别的岗位不会说的词"**。「吃」这种万能词会误伤，宁可少写几条。
- 岗位数建议 4（一人一块，4 人小组刚好）。5 个以上会有组凑不齐人。

## mindMap

```js
[{ key: '交通', label: '🚄 交通', subs: [{ id:'c1', text:'坐什么车去' }, { id:'c2', text:'下车后怎么走' }] }]
```

- `key` 必须与 `roles[].scope.name` 对得上（学生把卡片拖到分支下时靠它归类）。
- **建议 4 条主分支 × 2 个小任务**。样式按 4 列排版，5 条以上会挤，2 条以下不像"分解"。
- `subs[].id` 全局唯一，别和别的分支重名。

---

## cardRows

```js
[{ key: '景点安排', icon: '🏞️', tip: '景点 / 门票 / 开放时间' }]
```

- **顺序就是行程卡的显示顺序**，与 `roles` 的顺序无关（黄河例子里 `roles` 是交通在前，`cardRows` 是景点在前）。
- 每个 `key` 必须被某个 `roles[].cardRow` 引用，否则那一行永远没人能填。
- 4 行正好；6 行以上在 1366 宽下会横向溢出。

## questions / answers.js

`course.js` 里只有题面：

```js
{ id: 'q1', slide: 3, type: 'single', title: '…', options: ['分解思维','死记硬背',…], points: 2 }
```

`answers.js` 里给答案（**放在 `public/` 外，学生端取不到**）：

```js
module.exports = { q1: 0, q3: 1 };   // 值是正确选项的下标
```

- `slide` 只是注记（这题挂在哪页），**判分按 `id`**，所以 `slide` 写错不会算错分。
- 一节课 1–3 道题就够。这套东西的主体是"做任务"，不是刷题；题多了会打断节奏。
- `points` 默认 2。答题分值固定，别在这里做难度分级——那会让计分表变复杂。

## slides

```js
S(title, sub, act, quiz, students, tag, min, file, prompt)
```

| 参数 | 说明 |
|---|---|
| `title` | 页标题（可带 emoji，会自动转成图标） |
| `sub` | 大屏副标题，可用 `<b>` |
| `act` | 页面类型，见 `02-页面类型.md`；`null` = 纯图文 |
| `quiz` | 挂哪些题号，如 `['q1']` |
| `students` | **学生端看到的提示语**（和大屏副标题不是一回事，这句是"你该做什么"） |
| `tag` | 环节标签，如「活动一 · 分解」。同一 tag 的页会归到一个环节 |
| `min` | 建议分钟数。**加总要与课时对得上**，`verify.py` 会算 |
| `file` | 配图文件名，放 `public/ppt-images/` |
| `prompt` | 生成配图用的提示词（留着，下次换风格还能用） |

整页视频用 `V(slide, videos, endText, afterVideo)` 包一层：

```js
V(S('⚠️ 误信 AI 会怎样？', …), ['/videos/v03-official.mp4'])
```

视频页缺文件会**自动回落成静态图页**，不会黑屏。

**延迟播放**（翻到这页先显示图文，老师再按一次"下一页"才全屏播）：

```js
Object.assign(V(S(…), ['/videos/v03-card-demo.mp4'], '', 'slide'), { manualVideo: true })
```

用途：老师要先讲两句再放演示，不想被视频抢走注意力。**这个开关很好用，别当 bug 删掉。**
