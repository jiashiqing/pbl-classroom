# 05 · 验收与踩坑


## 这次（把黄河课抽成模板）实际踩的坑

### 1 · 答案不能进 `public/`

`course.js` 被浏览器直接加载，答案写进去学生按 F12 就能看。
所以拆成两个文件：

- `public/course.js` —— 题面（公开）
- `answers.js` —— `{ q1: 0 }`（项目根，**不托管**）

服务端 `require('../answers.js')` 合并成完整题库再判分。
`curl /answers.js` 必须返回 **404**，这是验收项之一。

### 2 · emoji 素材缺失会整页破图

`app.js` 有个「把 emoji 文本换成 `public/emoji/*.png`」的机制。素材包没带就全是裂图。
已加 `img.onerror` 回落成系统 emoji 文本。**换课时可以完全不准备 emoji 素材包**，
页面会显示系统 emoji，只是没那么好看。

### 3 · 删代码前先 grep 引用点

删掉 17 个死 action 后，`STAGE_DEFS` 还被 `/api/questions` 的 `stages` 字段引用，
`state.timer` 还被服务端 `setInterval` 引用——**语法检查过得去，跑起来直接 undefined**。
凡是删常量，先 `grep` 全仓。

### 4 · 归属校验会把"漏传 member"当场拦下

测试 `setCard` 时只传了 `teamId/key/t`，没传 `member`，服务端返回 `{ok:true}` 但没写入
（`canEditRow` 里 `if (!m) return false` 静默拒绝）。
**返回 `ok:true` 不等于写成功**——冒烟测试必须回读 state 确认字段真的变了。

### 5 · 后台起服务

在 Bash 工具里 `node server.js &` 会被 SIGTERM 杀掉，接着截图就 `ERR_CONNECTION_REFUSED`。
必须用 `run_in_background=true`。按端口杀进程：

```bash
PID=$(netstat -ano | grep ":5199" | grep LISTENING | awk '{print $5}' | head -1)
taskkill //F //PID $PID
```

### 6 · 截「登录后的学生端」需要种子页

`?mode=student` 默认是登录页。要截互动页得先有 `localStorage` 登录态。

JS 跳转（`location.replace`）在 headless 截图里不可靠——截到的是跳转前的页面或者干脆不出图。
可行做法：一个临时页写 localStorage，然后 **用全屏 iframe 加载真实页面**：

```html
<script>
localStorage.setItem('cls_me', JSON.stringify({ teamId:'T1', name:'测试甲' }));
document.write('<iframe src="/?mode=student"></iframe>');
</script>
```

（这个种子页只在测试时用，**不要带进交付目录**。）

### 7 · 中文脚本一律写独立 `.py` 文件

`python -c "…"` 里只要有反引号、`$`、`!`，会被 bash 先做命令替换/变量展开，
报一堆 `: Is a directory`。**写文件，再执行文件。**

### 8 · 页数上界不要在服务端写死

原来是 `SLIDE_COUNT = 16`，和前端 `SLIDES.length` 耦合，加一页忘了改，
**最后一页静默翻不到**（不报错，就是翻不过去）。
现在 `setSlide` 不设上界，由客户端钳制。

## 部署注意

| 项 | 说明 |
|---|---|
| 默认端口 | `5174`，`PORT=xxxx node server.js` 可改 |
| 机房访问 | 老师机起服务，学生访问 `http://<老师机内网IP>:5174/?mode=student` |
| 防火墙 | 首次运行 Windows 会弹"是否允许访问网络"，必须点允许 |
| 反代 | SSE 必须 `proxy_buffering off` + 长超时，否则翻页不实时 |
| 公网部署 | 别把 `config.json`（含 API key）放进 Web 目录 |
| 断网 | 除 AI 提问外全部可用；AI 会自动降级成示例答案 |

**学生机只需要浏览器，不需要装任何 exe。**
截图工具（可选）只解决"把学生平板上的截图贴进行程卡"，没有它就走 `Ctrl+V` 粘贴。
